# 월계 식당 패스

월계1동 식당과 학생·주민을 하나로 잇는 모바일 웹앱.
2026 광운대학교 KW해커톤 · 상권 활성화 트랙 · 16조 유구무언 (최유민, 류한솔, 오태호, 강진우)

## 왜 만드나

- 월계1동은 2024년 개업 121곳, 폐업 155곳(개업 대비 폐업률 128.1%). 새로 생기는 가게보다 사라지는 가게가 많다. (서울신용보증재단, 2025 노원구 상권분석 보고서)
- 가게는 홍보 방법이 없고 학생은 혜택이 있는 줄도 모른다. 제휴·할인은 동아리·단과대·학생회마다 달라서 내게 적용되는 것을 찾기 어렵다. 한산한 시간·마감 전·방학처럼 손님이 필요한 순간에 혜택을 주고 싶어도 즉시 알릴 길이 없다.
- 2028년 광운대역 복합쇼핑몰이 열리면 유동인구가 늘어난다. 그 전 2년 동안 폐점을 줄여 기존 점포를 지켜 두는 것이 목표다.

## 무엇을 만드나

| 기능 | 설명 |
|---|---|
| 제휴 모아보기 | 학생이 학부·동아리를 등록하면 자기에게 적용되는 제휴·할인만 자동으로 표시 |
| 타임세일 | 사장님이 원하는 시간대에 할인을 올리면 근처 학생에게 즉시 푸시 알림 |
| 식당별 스탬프 | 카운터 QR로 적립. 몇 개에 무엇을 줄지는 가게가 직접 설정 |
| 기여도 리그 | 학과·동아리 단위로 골목 방문을 겨뤄 가게가 따로 홍보하지 않아도 알려지게 |
| 사장님 화면 | 할인·스탬프 혜택 등록, 방문 시간대와 알림 반응 데이터 확인 |

기존 배달·예약앱의 할인이 미리 걸어 두는 정적 쿠폰이라면, 식당 패스는 사장님이 손님이 필요한 순간에 직접 올리는 동적 할인이다.

## 저장소 구성 (중간발표 시점)

```
prototype/index.html   클릭형 프로토타입 (HTML 한 파일, 브라우저에서 바로 열림)
docs/db-schema.sql     Supabase(PostgreSQL) 테이블 설계
docs/api-spec.md       API 명세 초안
media/ad_30s.mp4       30초 시연 영상
```

프로토타입은 `prototype/index.html`을 브라우저로 열면 된다. 하단 탭으로 화면을 옮기고, 식당 카드를 누르면 상세로 들어간다.
`?mode=ad`를 붙이면 시연 영상용 자동 재생, `?screen=home` 처럼 붙이면 특정 화면만 고정된다.

## 개발 예정 스택

- 프론트: Next.js(React) + Tailwind, PWA, 카카오맵 API, Web Push
- 백엔드/DB: Supabase (PostgreSQL, Auth, Realtime), RLS로 학생·사장님 권한 분리
- 인증: 학교 이메일(@kw.ac.kr), 휴대폰
- 배포: Vercel
- 데이터: 소상공인시장진흥공단 상가(상권)정보 API로 월계1동 업소 초기 적재

- 10.8~10.9 본선
